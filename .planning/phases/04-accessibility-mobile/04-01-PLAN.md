<threat_model>
## Trust Boundaries

This plan builds a client-side UI primitive (a modal wrapper) with no data fetching, no server
action calls, and no user-supplied input parsing. There is no trust boundary crossed by
`src/components/dialog.tsx` itself — it renders whatever `children` its caller passes, and callers
are internal, already-authorized components (task modals, delete confirm).

| T-04-02 | Information Disclosure | Dialog content (children) | accept | Dialog renders only content its caller already has authorization to show (task titles, form fields already scoped by RLS elsewhere) — no new data path introduced. |
