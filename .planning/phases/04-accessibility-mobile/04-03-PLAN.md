## Trust Boundaries

`layout.tsx`'s nav visibility is a UI convenience, not an authorization boundary — the actual route
protection (or lack of it) for `/tasks` when signed out is unrelated and explicitly deferred
(CONTEXT.md D-16: "the missing `/tasks` signed-out redirect... stays out of this phase"). Hiding nav
links does not grant or restrict access to anything; a signed-out user typing `/tasks` directly
still reaches whatever that route currently does. `tasks-page-client.tsx`'s viewport class change and
`login-card.tsx`'s render-timing fix are pure client-side presentation/state-derivation changes with
no data flow.
