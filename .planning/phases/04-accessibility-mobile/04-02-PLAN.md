<objective>
Close two independent audit gaps that share no files: global focus-visible styling (U2) and
split live-region toasts (U4). Both are additive changes to files nothing else in this phase
touches, so they run in Wave 1 with no dependencies.

Purpose: U2 — the current codebase has zero `:focus-visible` styling on buttons or links (inputs
only), so keyboard users cannot see where focus is. U4 — the current single `<div>` toast container
has no `aria-live`, so screen reader users never hear a toast fire.
Output: `--color-focus` token + one global CSS rule; `Toaster` split into two `aria-live` regions with
per-toast dismiss buttons, per CONTEXT.md D-10/D-11/D-12.
</objective>
